## Part B — backup-media.sh Script

Script created at `/home/rover/backup-media.sh` (staging location — needs root to copy to `/home/shelter/scripts/`):

```bash
#!/bin/bash
# Weekly animal-media backup — intended for Sundays 3:45am ET.
# Separate from the daily data tarball to keep it slim.
# animal-media contains AI-generated crops, thumbnails, and grok_imagine videos.
# The grok_imagine videos (385MB) are NOT re-derivable — they are unique AI generations.

set -o pipefail

BACKUP_DIR=/home/shelter/backups
LOG=/home/shelter/backups/backup-media.log
RETENTION_DAYS=28
TIMESTAMP=$(date +%Y%m%d)
ARCHIVE="$BACKUP_DIR/media-$TIMESTAMP.tar.gz"

log() {
  echo "[$(date -u +%Y-%m-%dT%H:%M:%SZ)] $*" >> "$LOG"
}

alert() {
  log "ALERT: $1"
  sudo -u shelter /home/shelter/scripts/send-alert.sh "Media backup: $1" 2>&1 | tee -a "$LOG"
}

log "=== Media backup start ==="

tar -czf "$ARCHIVE" \
  -C /home/shelter/shelter-apps/data \
  animal-media \
  2>>"$LOG"

if [ $? -ne 0 ] || [ ! -f "$ARCHIVE" ]; then
  alert "FAILED — tar did not produce archive at $ARCHIVE"
  exit 1
fi

SIZE=$(du -h "$ARCHIVE" | cut -f1)
FILE_COUNT=$(tar -tzf "$ARCHIVE" 2>/dev/null | grep -v '/$' | wc -l)
log "Created $ARCHIVE ($SIZE, $FILE_COUNT files)"

DELETED=$(find "$BACKUP_DIR" -name "media-*.tar.gz" -mtime +$RETENTION_DAYS -delete -print 2>/dev/null | wc -l)
log "Pruned $DELETED old media archives (>${RETENTION_DAYS} days)"

log "=== Media backup end ==="
exit 0
```

**Ownership:** Matches other backup scripts — root:root, mode 755. Currently staged at `/home/rover/backup-media.sh` because `/home/shelter/scripts/` is root-owned and rover lacks root sudo for file creation. **John needs to run:**
```bash
sudo cp /home/rover/backup-media.sh /home/shelter/scripts/backup-media.sh
sudo chown root:root /home/shelter/scripts/backup-media.sh
sudo chmod 755 /home/shelter/scripts/backup-media.sh
```
