## Step 3 — Proposed edit shape (prose, no implementation)

### What changes

1. **REPORT_DIR** changes from `/home/shelter/rover-reports` to `/home/rover/rover-reports-repo`

2. **REPORT_LATEST** stays as `$REPORT_DIR/health-check-latest.md` (same filename, new directory)

3. **REPORT_DATED** stays as `$REPORT_DIR/health-check-$(date +%Y%m%d).md` (same pattern, new directory)

4. **REPORT_URL** changes from `https://rover-reports.4lgshelterapp.duckdns.org/health-check-latest.md` to `https://raw.githubusercontent.com/jvitiel/rover-reports/main/health-check-latest.md`

5. **After writing the report files** (after the `cp` and before retention prune), add a git block:
   ```
   cd "$REPORT_DIR"
   git add health-check-latest.md "health-check-$(date +%Y%m%d).md"
   git commit -m "Health check $(date +%Y-%m-%d)"
   git push origin main
   ```

6. **Git push failure handling:** The push is **non-fatal**. If `git push` fails (network blip, auth), the script continues to send the Telegram alert. The alert URL will be a GitHub raw URL that may 404 until the next successful push, but the Telegram message body already contains the flag summary so the alert is still useful. A flag is added: `flag "⚠️ Git push failed for health-check report"` so the Telegram message itself mentions the push failure.

7. **chown line removed.** The rover-reports-repo is owned by rover, not shelter. The script runs as root via cron so it can write there. No chown needed.

8. **Header comments** (lines 5-6) updated to reflect new paths.

9. **Retention prune** stays as-is. The `find ... -mtime +56 -delete` still works — it'll clean old dated copies from the repo directory. These deletions will be picked up by the next week's `git add` (or we can add them to the git block). Simpler: change the prune to also `git add -A` so deletions are committed.

10. **Footer comment** (`*Generated by /home/shelter/scripts/health-check.sh*`) — unchanged, still correct.

### What does NOT change

- All data-gathering logic (system, services, network, database, backups, security)
- Flag thresholds
- Telegram message construction
- send-alert.sh invocation
- Send log write
- The script's exit behavior

### Summary of touched lines

~8 lines modified (REPORT_DIR, REPORT_URL, 2 header comments, chown removal), ~6 lines added (git block with failure handling). No structural changes to the script's flow.
